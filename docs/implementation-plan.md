# Afreen implementation plan

Spec: [the complete assignment](../.codex-task.md). The assignment authorizes independent execution; no commits, global configuration changes, public deployment, production services, or edits outside this project.

Architecture: TypeScript data and route helpers, a native Node static-page generator, native HTML controls and a small client script. Astro was preferred but unavailable in the offline package cache; this is the assignment's allowed simpler robust static-stack fallback. No database or delivery service. Forest green, warm ivory, terracotta, serif headlines and restrained sans body typography. Original illustrative images supplied by Hermes remain untouched.

- [x] Slice 1 — catalogue and equivalent localized routes. Tests first for twelve unique products, category counts, Spanish names, search and product route switching; absence recorded red; implemented `src/data/catalog.ts`, `src/lib/routes.ts`; recorded green.
- [x] Slice 2 — quote domain. Validation and safe selection parsing/summary tests first (missing fields, invalid quantities, units, consent, unknown IDs, PII exclusion); absence recorded red; implemented `src/lib/quote.ts`; recorded green. Additional assertion-level red/green for decimal comma support.
- [x] Slice 3 — static site. Tests first against generated HTML for bilingual routes, unique metadata, reciprocal alternates, schemas, links, images, sitemap and 404 exclusions. Absence recorded red. Implemented shared layout, cards, content and all page families. Build and generated-site tests pass.
- [x] Slice 4 — browser workflows. Wrote local-only Playwright tests before the browser implementation. Primary-agent browser run was blocked before assertions by sandbox EPERM, so a genuine browser assertion-level red could not be observed. Implemented browser behavior; Hermes independently ran all 16 cases successfully. See the report for evidence attribution and final screenshot-helper changes.
- [x] Slice 5 — verify and document. Strict TypeScript/syntax checks, unit/integration tests, build, generated-site checks and image hashes pass. Primary-agent E2E and network audit remain sandbox-blocked; Hermes supplied passing E2E and zero-vulnerability audit evidence. Reviewed supplied screenshots. README, AGENTS, launch checklist and honest report delivered. Browser-specific limitations remain documented.

Commands: `npm run check`, `npm test`, `npm run build`, `npm run test:site`, `npm run test:e2e`, `npm audit`. Log results in `artifacts/`. Browser tests launch a disposable preview bound to `127.0.0.1:4321`, never accept a production base URL, and block external requests. Screenshots are written under `artifacts/`. No commits or branch integration steps apply; the user prohibited them.

Launch blockers: owner-approved real contacts and delivery integration; verified business/address and product claims; domain/HTTPS/hosting approval; search-engine verification and submission; Google Business Profile eligibility review. Demo contacts remain text only. Only product IDs are persisted; contact details remain in memory until the visitor explicitly copies or downloads a summary.
